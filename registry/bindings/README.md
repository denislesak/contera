# Reserved — populated bindings go here

This directory is intentionally empty. It is the architectural seam for the populated implementation-binding registry described in `registry/README.md`.

Populate it only once real rendered surfaces exist to bind (the demo application described in the architecture audit). Until then, an empty directory here is correct, not incomplete — do not pre-populate it with placeholder or example bindings, per the same discipline this Context System applies to unresolved product policy (`context/manifest.md` §6): a gap should stay visibly a gap, not be filled with a plausible-looking stand-in.
